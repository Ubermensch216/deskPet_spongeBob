# 비키니 친구들 — 바탕화면을 돌아다니는 스폰지밥 일행

`deskPet_Neoburi`(너부리)와 **같은 기능**의 데스크톱 펫이고, 캐릭터를 `ref/characters.png` 의 여섯 명으로 바꿨습니다.
**스폰지밥 · 뚱이 · 징징이 · 다람이 · 집게사장 · 플랑크톤**이 각자 다른 몸 구조(리그)로 그려지고, 걸음걸이·표정·소품·대표 동작이 모두 다릅니다. (원본 `deskPet_Neoburi` 는 그대로 두었습니다.)

## 실행
`output\bikini_friends.exe` 를 실행하면 됩니다. 설치가 필요 없고(.NET Framework 4.8 — Windows 10/11 기본 포함), 그림은 코드로 그려서 EXE 한 개에 들어 있습니다.
설정·기록은 `%AppData%\비키니친구들\` 에 저장됩니다. 처음엔 무작위 한 명이 나오고, 우클릭 → “한 마리 더 부르기”에서 원하는 친구를 고를 수 있습니다(최대 16마리, 앞에 연 친구 구성은 다음 실행에 기억).

## 사용법 (너부리와 동일)
| 조작 | 동작 |
|---|---|
| 클릭 | 발끈(💢) → 달달 떨며 울기 → 폴짝 뛰기 순서로 반응 (설정에서 변경) |
| 끌어서 놓기 | 살짝 놓으면 낙하 도구로 천천히 하강, 휙 던지면 날아간 뒤 내려옴 |
| 우클릭 | 한 마리 더 부르기, 보내기, 간식 주기, **동작 바로 보기(★ 대표 동작)**, 설정, 도우미 … |
| 커서를 가까이 | 혀를 내밀고 전력 질주로 도망 (움직임 설정에서 “따라오기”로 변경 가능) |
| 트레이 아이콘 | 더블클릭 = 모두 숨기기/보이기, 우클릭 = 메뉴 |

숨은 반응(머리 위에서 마우스 한 바퀴 → 어질어질, 친구 둘 이상이면 몰래 군무, 10초 안에 3번 던지면 비밀 조종사)과 벽·천장·열린 창 타기, 친밀도·포만감·선물, 점심·퇴근·정각 알림, 할 일·메모·타이머, 자동 시작은 그대로입니다.

## 캐릭터별 특징 (이 프로젝트의 핵심)
참고 이미지의 모습과 원작의 상징적인 동작·소품을 바탕으로 만들었습니다.

| | 걸음걸이 | 대표 동작(쉴 때 가끔) | 낙하 도구 | 간식 | 선물(친밀도 100 단위) | 그 밖 |
|---|---|---|---|---|---|---|
| **스폰지밥** | 통통 튀며 팔을 크게 흔드는 신나는 걸음 | **해파리 잡이**(그물 휘두르면 해파리가 번쩍) / **비눗방울 불기** | 분홍 **해파리** | 크러스티 버거 | 바닷속 꽃다발 | 눈물이 줄줄 흐르며 엉엉 울기, 나이트캡 |
| **뚱이** | 뒤뚱뒤뚱 오리걸음(몸·머리 좌우로) | **바위 밑에 숨기**(바위가 떨어져 덮고 팔만 흔들다 들려 올라감) | 알록달록 **프로펠러 모자** | 아이스크림 | 커다란 아이스크림 | 낮잠 때 코에서 부푸는 콧방울, 별 모양 점프 |
| **징징이** | 뻣뻣하고 긴 보폭, 투덜대며 고개를 숙임 | **클라리넷 연주**(눈 감고 심취, 삑! 하면 눈 번쩍, 삐걱대는 음표) | 시무룩한 **검정 우산** | 피자 | 자화상 액자 | 클릭하면 팔짱 끼고 노려봄 |
| **다람이** | 자신만만하고 씩씩한 걸음, 꼬리가 출렁 | **가라테**(준비→손날 베기→높이 차기) / **올가미 돌리기** | 머리 위에서 도는 **올가미** | 도토리 | 도토리 꽃다발 | 폴짝 뛰면 공중 앞돌기, 헬멧 속 물방울 |
| **집게사장** | 정면 그대로 **옆걸음으로 후다닥**, 집게를 딱딱 | **돈 세기**(눈이 $, 금화가 튀고 더미가 쌓임) | **달러 지폐 낙하산** | 금화(깨물어 봄) | 번쩍이는 금화 | 잘 때 돈주머니를 끌어안고 $ 가 떠오름 |
| **플랑크톤** | 몸을 숙이고 뒷짐 진 종종걸음 | **음모 꾸미기**(설계도 펼치고 번개와 함께 으하하) | 자주색 **악당 프로펠러** | 몰래 먹는 버거 | 리본 맨 두루마리 | 외눈이 화나면 눈썹이 굵게 |

공통: 숨쉬기, 약 4초마다 깜빡임, 두리번거리는 시선, 안테나·눈자루·꼬리 흔들림, 앉기·기지개·멍때리기(생각 구름 안에 각자의 그림)·하품 등은 모두 캐릭터에 맞게 달라집니다.

## 빌드
```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```
.NET SDK 의 Roslyn 으로 .NET Framework 4.8 대상 EXE 를 만듭니다(`output\bikini_friends.exe`). 아이콘(`assets\bikini_friends.ico`)이 없으면 스폰지밥 얼굴로 자동 생성합니다.

## 점검 모드 (개발용)
```
bikini_friends.exe --selftest <폴더>                 설정·기록 저장, 친밀도 계산, 상태 전이 점검
bikini_friends.exe --ui-test  <폴더>                 모든 창 띄우기·실제 마우스 입력 점검(전체 화면 앱이 앞에 있으면 불안정할 수 있음)
bikini_friends.exe --render-test <폴더> [배율]       캐릭터별 모든 모습의 시트(sheet_*.png)와 시간 흐름 연속 컷(motion_*.png)
```

## 파일 구성 (`src/`)
`Rig.cs` 포즈·공통 그리기 도우미(팔 IK·눈·입·눈물) · `Rig*.cs` 캐릭터 6명의 부위별 그림 · `Props.cs` 손에 든 소품·간식 · `Decor.cs` 낙하 도구·선물·대표 동작 효과·생각 구름·잠옷 · `PetPoses.cs` 상태별·캐릭터별 자세 · `PetRender.cs` 자세 → 비트맵 · `Art.cs` 크기·캐릭터 정보(대사 포함) · 나머지는 너부리와 같은 상태기계·창·설정 코드.
